# Dota 2 Helper

Красивый помощник для Dota 2 в стиле iOS: игровые таймеры, анализатор драфта,
оверлей поверх игры и тренер комбо. **Полностью fair-play** — приложение ничего
не читает из игры и ничего не отправляет в неё, поэтому не может привести к
бану VAC/Overwatch.

## 🪟 Установка на Windows (пошагово)

### Шаг 1. Установи Python

1. Зайди на https://www.python.org/downloads/ и нажми жёлтую кнопку
   **Download Python 3.12.x** (подойдёт любая версия 3.10 и новее).
2. Запусти скачанный установщик.
3. ⚠️ **ВАЖНО:** в самом низу первого окна поставь галочку
   **«Add python.exe to PATH»** — без неё команды ниже не будут работать.
4. Нажми **Install Now** и дождись окончания.

Проверка: нажми `Win + R`, введи `cmd`, нажми Enter и в чёрном окне набери:

```bat
python --version
```

Должно показать что-то вроде `Python 3.12.4`. Если пишет
«не является внутренней или внешней командой» — переустанови Python с галочкой PATH.

### Шаг 2. Скачай программу

**Способ А — без Git (проще):**

1. Открой https://github.com/Astaral-graf/python/tree/claude/dota2-helper-gui-overlay-oqeja2
2. Нажми зелёную кнопку **Code → Download ZIP**.
3. Распакуй архив, например в `C:\dota2-helper`.
   Внутри будет папка `dota2_helper` — она нам и нужна.

**Способ Б — через Git:**

```bat
git clone -b claude/dota2-helper-gui-overlay-oqeja2 https://github.com/Astaral-graf/python.git C:\dota2-helper
```

### Шаг 3. Установи зависимости

Открой командную строку (`Win + R` → `cmd` → Enter) и выполни:

```bat
cd C:\dota2-helper\dota2_helper
pip install -r requirements.txt
```

Установится PySide6 (~150 МБ) — это библиотека интерфейса, нужно подождать пару минут.

### Шаг 4. Запусти

```bat
python main.py
```

Готово — откроется окно приложения. 🎉

### Шаг 5 (по желанию). Ярлык для запуска в один клик

1. В папке `C:\dota2-helper\dota2_helper` создай файл `start.bat` (правый клик →
   Создать → Текстовый документ, вставь строки ниже и сохрани как `start.bat`):

```bat
@echo off
cd /d %~dp0
start "" pythonw main.py
```

2. Теперь двойной клик по `start.bat` запускает программу без чёрного окна консоли.
   Можно кинуть ярлык на рабочий стол.

### Чтобы оверлей был виден поверх Dota 2

В настройках Dota 2: **Настройки → Видео → Режим отображения →
«Окно без рамок» (Borderless Window)**. В полноэкранном (Exclusive Fullscreen)
режиме Windows не показывает окна поверх игры.

### Если что-то не работает

| Проблема | Решение |
|---|---|
| `python не является командой…` | Переустанови Python с галочкой **Add to PATH** |
| `pip не является командой…` | Используй `python -m pip install -r requirements.txt` |
| Ошибка при установке PySide6 | Обнови pip: `python -m pip install --upgrade pip` и повтори |
| Окно не открывается | Запусти через `python main.py` из консоли и посмотри текст ошибки |
| Оверлей не виден в игре | Включи режим «Окно без рамок» в настройках видео Dota 2 |

## Возможности

- **⏱ Dashboard** — игровые часы (синхронизируешь один раз с таймером матча) и
  автоматический трекинг всех событий:
  - руны богатства (каждые 3:00), силы (с 6:00 каждые 2:00), мудрости (каждые 7:00),
    водные (2:00 и 4:00), лотосы (каждые 3:00)
  - напоминание о стаках лагерей (x:53), смена дня и ночи
  - Рошан: окно возрождения 8:00–11:00, истечение Аегиса
  - Торменторы обеих сторон (20:00, респаун 10:00)
  - обсервер-варды: нажал «Placed» — за 30 секунд до истечения придёт напоминание
  - тиры нейтральных предметов (7:00 / 17:00 / 27:00 / 37:00 / 60:00)
  - калькулятор байбека: вводишь нетворс — получаешь цену выкупа
- **🎯 Draft Assistant** — анализатор пиков на стадии выбора героев:
  - отмечаешь пики своей команды, врагов и баны (75+ героев, поиск по имени)
  - движок считает лучший пик по базе контрпиков и синергий и объясняет каждую
    рекомендацию: *counters Huskar*, *synergy with Magnus*, *adds hard disable*
  - фильтр по позиции (1–5): подсказки именно под твою роль
  - живой анализ состава: контроль, инициация, сейвы, баланс физического и
    магического урона + предупреждения («нет инициатора» и т.п.)
- **🖥 Оверлей** — полупрозрачная стеклянная панель поверх игры с часами,
  статусом Рошана и ближайшими событиями. Перетаскивается мышью, есть режим
  «клики насквозь» и настройка прозрачности.
- **⚡ Combo Trainer** — тренер комбо для популярных героев (Lion, Lina, SF,
  Magnus, Invoker, Storm, Puck, Earthshaker): подсвечивает клавиши в реальном
  темпе каста с регулировкой скорости. Открой *Demo Hero* и повторяй за
  подсветкой — так нарабатывается мышечная память.
- **🎨 Дизайн в стиле iOS** — тёмная тема, glassmorphism, скруглённые карточки,
  анимированные переключатели, segmented controls.

## Почему нет авто-комбо

Программы, которые сами нажимают клавиши за игрока, нарушают правила Steam/Valve
и приводят к бану аккаунта. Вместо этого Combo Trainer учит руки исполнять комбо —
это безопасно и в итоге полезнее.

## Структура

```
dota2_helper/
├── main.py               # точка входа
├── app/
│   ├── theme.py          # палитра iOS, шрифты, глобальный QSS
│   ├── widgets.py        # IOSSwitch, GlassCard, PillButton, KeyCap…
│   ├── game_state.py     # игровые часы и расписание событий
│   ├── combos.py         # библиотека комбо
│   ├── draft.py          # база героев, матрица контрпиков/синергий, скоринг
│   ├── draft_page.py     # страница Draft Assistant
│   ├── overlay.py        # оверлей поверх игры
│   ├── pages.py          # Dashboard, Combo Trainer, Settings
│   └── main_window.py    # безрамочное главное окно с сайдбаром
└── requirements.txt      # PySide6
```
